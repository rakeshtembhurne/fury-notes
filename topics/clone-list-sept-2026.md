# Clone List — Startups Making Money Right Now (Sept 2026)

> Goal: pick, copy, sell. Speed-to-revenue is the only ranking metric.
> Rule: validate with a single tweet before building. Replies > likes = signal.

## Ranked by fastest money

### 1. Reddit lead finder (clone: reddit grow)
- Proof: reddit grow at $1,102 MRR, asking $40K, 1,590% 30-day growth (TrustMRR live)
- What: find buying conversations in a niche on Reddit, AI-draft the reply, track threads
- Build: 3–5 weeks. Price: $29–49/mo. Exit: 3–5x
- Why first: live listing proves buyers pay right now, growth curve vertical

### 2. Website chatbot on your docs (clone: Chatbase)
- Proof: Chatbase ~$50K MRR within months, solo founder (Danny Postma)
- What: business trains chatbot on docs/FAQs, embed widget, charge per messages
- Build: 1–2 weeks (RAG is solved). Price: $19–99/mo. Exit: 3–5x
- Why: every business wants 24/7 support without hiring; RAG finally works

### 3. Content repurposer (clone: Castmagic / Opus Clip pattern)
- Proof: Castmagic $30K+ MRR year one; Opus Clip past $5M ARR, raised $20M
- What: one input (video/audio) → LinkedIn + X + blog + newsletter outputs
- Build: 1–2 weeks. Price: $19–99/mo. Exit: 3–5x
- Angle: niche down — repurposer for realtors, coaches, newsrooms (Khabar reuse)

### 4. Churn recovery (clone: Churnkey)
- Proof: Churnkey $30K MRR, documented 18% churn reduction for clients
- What: predict failed payments, smart retries, recovery emails
- Build: 2–3 weeks. Price: $50–500/mo or % of recovered revenue. Exit: 3–5x
- Why: 5–10% involuntary churn = ROI pitch writes itself

### 5. Screenshot skill for coding agents (clone: the /ss pattern)
- Proof: direct "build me this" demand in AI coding timelines; screenshot workflows recurring pain
- What: `/ss 3` reads screenshots folder, shows last N, ask questions (Codex/Claude plugin)
- Build: 3–7 days. Price: $9–19/mo. Exit: 3–5x dev tools
- Why: fastest build on this list; vibe-coder audience pays

### 6. App Store screenshot A/B tester (clone: cheap PickFu)
- Proof: PickFu charges $150/test; indies beg for cheap/fast alternative; 99% skip testing
- What: upload 2 screenshot sets → shareable test link → conversion winner
- Build: 5–10 days (static v1). Price: $19–49/test or $29/mo. Exit: 2–4x

### 7. Time tracker → one-click invoice (clone: Runey pattern)
- Proof: Runey listed on TrustMRR; solopreneur billing pain is constant
- What: track time, one click → invoice, send, get paid. $9–15/mo
- Build: 2–3 weeks. Price: $9–15/mo. Exit: 2–4x

### 8. Micro-SaaS boilerplate (sell before building)
- Proof: "IKEA furniture" complaint (auth+DB+payments+landing) repeats everywhere
- What: one Codex prompt/repo: auth + DB + Stripe + landing. Sell as template first
- Build: 1–2 weeks (sell Notion + repo in days). Price: $49–149 one-time + $19/mo updates

### 9. Abandoned-app flip finder (directory, not SaaS)
- Proof: operator doing $3.6M/yr finding 50K+ download apps untouched 18+ months, $2–3K offers
- What: directory of high-download dead apps, ranked by flip potential
- Build: 1–2 weeks. Monetize: listing fees + affiliate. Fastest first dollar

### 10. OpenClaw/Hermes memory skill pack
- Proof: #1 complaint across agent timelines: "my agent doesn't remember"
- What: prebuilt persistent-memory + context skills for OpenClaw/Hermes/Codex
- Build: 1–2 weeks. Price: $29–99 one-time + templates. Exit: 3–5x

## Buy instead of build (TrustMRR live)
- Reddit scraper $72 MRR → sold $2,000 (28x). Reading club $700 MRR → $12,000 (17x)
- Micro-tools flip at 17–33x; consumer apps at 2–3x. A $2–10K buy can beat a month of building
- Rule: buy only if it runs without the founder (buyers pay for independence)

## Do NOT clone
- Meeting-notes (Fireflies $10M ARR — crowded, funded giants own it)
- Generic AI wrappers with no niche
- Horizontal tools, "agents that run startups" (no validated market)
- Anything needing >8 weeks before first dollar
